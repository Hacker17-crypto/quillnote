# 04 — AI (all via local Claude Code)

## Bridge (Electron main process)
- Detect CLI: `claude` on PATH (Windows: also `%USERPROFILE%\.local\bin\claude.exe`;
  macOS: `/usr/local/bin`, `/opt/homebrew/bin`, `~/.local/bin`). Show status in
  Account panel → Integrations ("Claude Code: Connected v…" / "Not found — install guide").
- Run non-interactively: `claude -p "<prompt>" --output-format stream-json --verbose`
  (stream tokens into the UI) or `--output-format json` for structured tasks.
  Working directory: a temp folder per request containing the files Claude needs
  (page PNG renders, extracted text as .md). Tell Claude the file paths in the prompt.
  Allow only read tools: `--allowedTools "Read"`; never give write/bash permissions.
- Use `child_process.spawn` (no shell), pass the prompt via stdin to avoid quoting issues.
  Support cancel (kill process), 120s timeout, friendly error toast.
- Expose to renderer via `contextBridge`: `ai.ask(payload)`, `ai.cancel(id)`, `ai.status()`.

## Features
1. **Ask / chat about notes** — context = recognised text of current page/document/selection
   + page images when handwriting not yet recognised.
2. **Handwriting → text** (lasso action + "Recognise document" in More) — render selection
   to PNG, ask Claude to transcribe exactly; cache result in `page.ocrText` for search.
   Option "Replace with text box".
3. **Summarize** page / document / recording → inserted as text box or new page.
4. **Spellcheck & rewrite** handwriting (shows corrections as tooltips; "Apply").
5. **Math assist** — detect handwritten equation in lasso, solve with steps.
6. **Quiz / flashcards** — generate Q&A from document; study mode overlay (flip cards,
   "Got it / Again" spaced repetition stored per doc).
7. **Create** — prompt → Claude returns SVG (diagram, flowchart, mind map, table, template,
   simple illustration) → placed as editable image element. Also "Create page template"
   (returns SVG background). No raster image generation.
8. **Record & Summarize** — audio recorded in renderer (MediaRecorder, webm/opus) →
   transcribed **locally** with Whisper via `@huggingface/transformers` (`whisper-base`,
   model downloaded once to app data, with progress bar) → transcript sent to Claude for
   summary + key points + action items. Transcript and summary viewable in "Show Recordings".
9. **Smart search** — natural-language search ("where did I write about mitochondria") →
   Claude ranks page snippets from the index.
10. **Auto-title** — suggest a notebook title from first page content.

## Prompts
Keep prompt templates in `src/main/ai/prompts.ts`; each requests a strict output format
(markdown, or JSON with schema for structured features). Validate JSON; retry once on parse error.
